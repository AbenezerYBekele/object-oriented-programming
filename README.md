# Java Object Oriented Programming

A collection of Java projects demonstrating **Object-Oriented Programming (OOP)** concepts using **Java Swing**.

## Projects

### 🍕 Pizza Shop

A Java Swing GUI application for creating a pizza order, selecting toppings and size, and calculating the total price.
[View PizzaShop.java](https://github.com/AbenezerYBekele/object-oriented-programming/blob/main/PizzaShop.java)
**OOP concepts:** Classes, objects, inheritance, encapsulation, constructors, interfaces, polymorphism, and event handling.
### 📐 Rectangle Calculator
A Java Swing GUI application that calculates the **area and perimeter of a rectangle** based on user input.
[View GUI RectangleCalculator.java](https://github.com/AbenezerYBekele/object-oriented-programming/blob/main/GUI%20RectangleCalculator.java)
**OOP concepts:** Classes, objects, inheritance, encapsulation, constructors, interfaces, and event handling.
